# AWS Developer Associate — MCQ Mock Test (Personal Practice Project)

![Landing Page Preview](https://raw.githubusercontent.com/vinsin21/Quiz_AWS_DAV-CO2-/main/screenshot.png)

This is a personal project I built to practice for the AWS Developer Associate certification. It’s a simple mock-test style quiz app that I use while preparing — and I made it public so others can use it too.

## What this project includes

- **387+ questions** updated for 2025
- **Multiple mock tests**: Each mock test has 50 MCQs
- **Comprehensive Exam**: The last mock test has 87 questions
- **Accessibility**: Free to use, no signup, no payments

I mainly use it to simulate exam practice sessions and quick revisions.

## Why I built this

While preparing for the AWS Developer Associate exam, I wanted something that was:
- Simple and distraction-free
- Easy to repeat tests
- Focused only on practice questions

Most tools were either paid or overloaded with extra features, so I built my own quiz app for regular practice.

## How it works

1. **Select** a mock test from the practice list.
2. **Answer** the questions (supports both single and multiple-choice).
3. **Submit** or **Pause**: You can resume an unfinished test anytime.
4. **Review**: View your score and correct answers immediately.

## Tech stack

This is a modern web application built for speed and aesthetics:
- **React 19** - For the UI logic.
- **Three.js / React Three Fiber** - For the high-performance ethereal background effects.
- **Tailwind CSS** - For responsive, modern styling.
- **Framer Motion** - For smooth page transitions and interactive elements.
- **Lucide React** - For the iconography.

## Installation and running the project

You need **Node.js** installed on your system (any recent LTS version is fine).

1. **Clone the repo**
   ```bash
   git clone https://github.com/vinsin21/Quiz_AWS_DAV-CO2-
   cd Quiz_AWS_DAV-CO2-
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the dev server**
   ```bash
   npm run dev
   ```

The app will be running locally in your browser (usually at `http://localhost:5173`).
